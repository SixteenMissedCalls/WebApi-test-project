# Тестовое задание: Шлюз для курсов валют Банка России

## Описание проекта
Проект представляет собой веб-API на .NET Core 3.1, которое выступает в качестве шлюза для получения информации о курсах валют с сайта Банка России. Приложение обрабатывает GET-запросы, возвращая данные в формате JSON.

## Функциональность
- **Основной функционал**:
  - Получение курса валют по коду валюты и дате (если параметры не переданы, используются текущая дата и список всех валют).
  - Возврат ответа в формате JSON (код 200) или пустого ответа (код 204), если валюта не найдена.
  
- **Дополнительные задачи**:
  - Описание API в OpenAPI 3.0.
  - Настройка Jenkins пайплайна для сборки и контейнеризации.
  - Предложения по асинхронному получению данных с сайта Банка России.

## Требования
- .NET Core 3.1
- Доступ к сайту Банка России для получения данных о курсах валют.
